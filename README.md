# HomeWise AI
The Groq Home Repair Bot is a conversational AI assistant that specializes in providing guidance for home repair, maintenance, and DIY improvement projects. Think of it as having a friendly, knowledgeable handyman available to chat whenever you need advice. The bot can help with a wide range of household issues, from fixing dripping faucets and patching drywall holes to silencing squeaky floors and troubleshooting electrical problems.

#Setup
1.Clone this repository

2.Install dependencies: pip install -r requirements.txt

3.Get your Groq API key from https://console.groq.com

4.Create .env file with GROQ_API_KEY=your_key

5.Run: streamlit run app.py
